# Pertemuan 1 — Pengenalan Information Retrieval
Pada pertemuan pertama, pembelajaran berfokus pada pengenalan konsep dasar **Information Retrieval (IR)** dan bagaimana sebuah sistem pencarian bekerja mulai dari pemrosesan dokumen hingga pencarian berbasis makna.

## Konsep yang Dipelajari
### 1. Text Preprocessing
Tahap awal dalam Information Retrieval adalah mempersiapkan teks agar dapat diproses oleh sistem.
Pada latihan sederhana dilakukan:
- lowercase
- tokenization
- pemisahan teks menjadi kumpulan term
